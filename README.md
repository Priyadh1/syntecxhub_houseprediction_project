## 📌 Project Overview

**Smart House Price Prediction using Multiple Linear Regression** is a machine learning project that predicts the estimated price of a house based on its property details.

The model uses features such as:

- Area in square feet
- Number of bedrooms and bathrooms
- Property age
- Location
- Furnishing status
- Property type
- Parking spaces
- Garden availability
- Distance from the city center

The project includes data cleaning, exploratory data analysis, feature selection, categorical feature encoding, model training, and evaluation using **RMSE and R²**.

A trained model is saved using Joblib and integrated into a **Streamlit web application**, allowing users to enter house details through a simple form and receive an estimated house price instantly.

### 🎯 Objective

To build a simple and practical machine learning solution that demonstrates how multiple property features can be used to estimate house prices.

### 🔄 Project Workflow

**Dataset → Data Cleaning → EDA → Feature Selection → Preprocessing → Train/Validation/Test Split → Multiple Linear Regression → Evaluation → Model Saving → Streamlit App**

### 📊 Model Performance

- **Validation RMSE:** 31,525.26
- **Validation R²:** 0.9504
- **Test RMSE:** 39,134.60
- **Test R²:** 0.9241
